## FlowZX 4.4.0 — 内置 Xray 内核

在 sing-box 主核之外随包内置 **Xray-core 26.3.27**（sidecar，普通用户权限），承载 sing-box 不支持的 Xray 独有协议组合；其余节点仍由 sing-box 承载，行为不变。

### 新增
- **VLESS + XHTTP + REALITY + ENC**（VLESS Encryption `mlkem768x25519plus.*`，后量子）
- VLESS / VMess / Trojan + **XHTTP** + TLS（packet-up / stream-up / stream-one / auto，支持 `extra`：xmux、上下行分离等）
- REALITY **ML-DSA-65**（`pqv`）、`xtls-rprx-vision-udp443`、证书指纹固定 `pinnedPeerCertSha256`（`pcs`）
- 「自定义出站 JSON」可选 **Xray** 内核：任意 Xray outbound（mKCP + finalmask、hysteria、wireguard…）原样运行
- 导入：分享链（`type=xhttp|splithttp`、`mode`、`extra`、`encryption`、`pqv`、`pcs`、`ech`…）、Clash/mihomo `xhttp-opts`、Xray JSON 配置
- 节点列表 **Xray** 角标；设置 → 内核管理显示 Xray 版本/状态，支持在用户目录 `xray_core/` 放置自定义 Xray 覆盖随包版本
- 热切换、规则指定节点、测速、出口 IP 检测、前置代理（代理链，fail-closed）与原生节点一致；Xray 意外退出自动重拉

详见 [docs/XRAY.md](https://github.com/mutsuki14/FlowZX/blob/main/docs/XRAY.md)。

## FlowZX 4.4.0 — Bundled Xray core

FlowZX now bundles **Xray-core 26.3.27** as a sidecar next to sing-box to run Xray-only protocol combos — **VLESS + XHTTP + REALITY + VLESS Encryption**, XHTTP over TLS for VLESS/VMess/Trojan, REALITY ML-DSA-65 (`pqv`), `xtls-rprx-vision-udp443`, pinned peer certificate SHA-256, and arbitrary custom Xray outbound JSON. Share links, Clash/mihomo `xhttp-opts` and Xray JSON configs import directly. All other nodes keep running on sing-box unchanged. See [docs/XRAY.md](https://github.com/mutsuki14/FlowZX/blob/main/docs/XRAY.md).
