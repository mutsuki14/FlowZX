## FlowZX 4.4.1 — 更新检查与问题反馈改为指向 FlowZX

应用内的更新检查、仓库链接与「报告问题」改为使用 FlowZX 自己的 Releases 与 Issues。

### 修复
- 「关于」页与托盘菜单中的「检查更新」、启动时的自动检查，以及「关于」页的仓库链接与「报告问题」，现在都指向 [mutsuki14/FlowZX](https://github.com/mutsuki14/FlowZX) 的 [Releases](https://github.com/mutsuki14/FlowZX/releases) 与 [Issues](https://github.com/mutsuki14/FlowZX/issues)。此前它们指向上游 FlowZ，可能把不含 Xray 内核的上游安装包当作更新提供。
- 更正「阻断 QUIC」与「切换节点时断开现有连接」的说明：前者新安装默认开启，后者默认开启（显式关闭过的保持关闭），此前的说明误写为默认关闭。这两项的实际默认值和已有设置不变。

### 4.4.0 用户请注意
4.4.0 的应用内更新仍会检查上游 FlowZ。请从 [Releases](https://github.com/mutsuki14/FlowZX/releases/tag/v4.4.1) 手动下载并覆盖安装一次 4.4.1（节点、订阅与规则会保留；便携版请用新 exe 替换原目录中的旧 exe，数据在它旁边的 `data\`），之后的更新即可在应用内完成。如果 4.4.0 提示有新版本，请不要安装：那是上游 FlowZ 的安装包，不含 Xray 内核。

## FlowZX 4.4.1 — Update checks and issue reports now point to FlowZX

**Check for Updates** on the About page and in the tray menu, the automatic check at startup, and the About page's repository link and **Report an issue** now use [FlowZX's Releases](https://github.com/mutsuki14/FlowZX/releases) and [Issues](https://github.com/mutsuki14/FlowZX/issues). Previously they pointed to upstream FlowZ and could offer upstream builds, which don't include the Xray core, as updates. The descriptions of **Block QUIC** and **Interrupt existing connections on switch** are corrected: Block QUIC is on by default for new installs, and Interrupt existing connections on switch is on by default unless you turned it off (they previously said off by default); the actual defaults and your existing settings are unchanged.

**Upgrading from 4.4.0:** 4.4.0's in-app updater still checks upstream FlowZ, so download 4.4.1 from the [Releases page](https://github.com/mutsuki14/FlowZX/releases/tag/v4.4.1) and install it over your current version once (nodes, subscriptions and rules are kept; for the portable build, replace the old exe in its folder, since its data lives in `data\` next to it); later updates work in-app. If 4.4.0 reports a new version, don't install it — it is an upstream FlowZ build without the Xray core.
