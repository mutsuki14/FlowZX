## FlowZX 4.4.3 — 全新 LOGO

FlowZX 换上了新图标：青色圆角方块上的白色 Z，沿「\」方向切成上下两半、彼此咬合，Z 的「/」笔画与两半之间的切缝交叉成 X；上半代表 sing-box 主内核，下半代表 Xray 内核，整体略向前倾，表示流量从左向右流动。应用图标、托盘图标、「关于」页与 README 均已更新。

### 变更
- **新 LOGO**：Windows 安装包与程序图标、macOS 应用 / Dock 图标、Linux 图标、窗口图标、托盘图标、「关于」页与 README 全部换成新设计。16–48px 的小尺寸使用满版、加大标记的专用版本，任务栏 / 资源管理器里也清晰可辨。
- **macOS 菜单栏图标更清晰**：改用按 18pt 与 @2x 直接绘制的专用图标，Retina 屏上不再发虚（此前由 1024px 大图缩小，且只有 1x 版本）。已连接为青 / 蓝双色，未连接为灰色。
- **Windows 托盘图标按显示缩放取尺寸**：专用多尺寸图标（16–48px），100%–300% 缩放下都用对应尺寸的图像，不再由大图缩放。
- macOS 应用图标改按 Big Sur 网格留边，在 Dock 中与系统图标大小一致。
- 新增 `scripts/generate-icon.js`：由 `build/logo/` 中的 SVG 母版一次生成全部图标文件（用项目自带的 Electron，无需额外依赖）。

### 说明
- 升级后 macOS 若仍显示旧图标，是系统图标缓存未刷新：重新打开应用或注销后即会更新。
- 本版本没有功能与配置变化，节点、订阅与规则均保留。

### 4.4.0 用户请注意
4.4.0 的应用内更新仍会检查上游 FlowZ，请从 [Releases](https://github.com/mutsuki14/FlowZX/releases/tag/v4.4.3) 手动下载并覆盖安装 4.4.3（节点、订阅与规则会保留；便携版请用新 exe 替换原目录中的旧 exe，数据在它旁边的 `data\`）。4.4.1 及以上版本可直接在应用内更新。如果 4.4.0 提示有新版本，请不要安装：那是上游 FlowZ 的安装包，不含 Xray 内核。

## FlowZX 4.4.3 — New logo

FlowZX has a new icon: a white Z on a teal rounded tile, cut along its "\" axis into two interlocking halves, so the Z's "/" stroke and the channel between the halves cross to form an X. The upper half stands for the sing-box core and the lower half for the Xray core, and the mark leans slightly forward to suggest traffic flowing left to right. The app icon, tray icon, About page and README all use it.

**Changes:** The Windows installer and app icon, the macOS app / Dock icon, the Linux icons, the window icon, the tray icon, the About page and the README use the new design; at 16–48 px a full-bleed variant with a larger mark keeps it legible in the taskbar and file explorer. **The macOS menu bar icon is sharper:** it is now drawn natively at 18 pt and @2x instead of being scaled down from a 1024 px image with only a 1x representation, so it's no longer blurry on Retina displays (two-tone teal / blue when connected, gray when disconnected). **The Windows tray icon matches the display scale:** a dedicated multi-size icon (16–48 px) supplies the right frame at 100%–300% scaling instead of a scaled-down large image. The macOS app icon now follows the Big Sur grid margins, so it matches the size of system icons in the Dock. New `scripts/generate-icon.js` regenerates every icon file from the SVG masters in `build/logo/` using the project's own Electron (no extra dependencies).

**Notes:** If macOS still shows the old icon after upgrading, its icon cache hasn't refreshed yet; reopening the app or logging out updates it. This release has no feature or configuration changes; nodes, subscriptions and rules are kept.

**Upgrading from 4.4.0:** 4.4.0's in-app updater still checks upstream FlowZ, so download 4.4.3 from the [Releases page](https://github.com/mutsuki14/FlowZX/releases/tag/v4.4.3) and install it over your current version (nodes, subscriptions and rules are kept; for the portable build, replace the old exe in its folder, since its data lives in `data\` next to it). 4.4.1 and later update in-app. If 4.4.0 reports a new version, don't install it — it is an upstream FlowZ build without the Xray core.
