## FlowZX 4.5.0 — 切换 Xray 内核版本（含预发布版）

「设置 → 高级」新增独立的「Xray 内核（sidecar）」卡：可以在线安装 XTLS 官方发布的任意 Xray 版本（包括预发布版），按官方 SHA2-256 校验并自检后切换，随时一键恢复随包版本。GitHub 上 v26.3.27（即随包版本）之后的 v26.4.13 … v26.10.10 都是预发布版，打开「包含预发布版本」即可选择。

### 新增
- **Xray 版本选择**：下拉列表列出带本平台构建的版本（标出预发布 / 当前 / 随包），选中后「安装」；可打开发行说明。列表由主进程缓存 10 分钟，「刷新列表」强制刷新。
- **包含预发布版本**开关：默认只列稳定版；打开后同时列出 GitHub 标记为 pre-release 的版本。预发布版未经 FlowZX 测试，安装前会二次确认。Xray 不会后台自动更新，只在你点击时安装。
- **完整性与兼容性检查**：
  - 下载地址与摘要由主进程按版本号现查 GitHub。
  - 压缩包须匹配官方 SHA2-256：取自 GitHub API 的 digest，以及直连 github.com 下载的 `.dgst`（不经镜像）。两者都有时须一致，都取不到则拒绝安装。
  - 只解出 `xray` 一个文件，用内置解压器，不依赖系统的 unzip / PowerShell。
  - `xray version` 须与所选版本一致；再用新内核 `xray run -test` 当前配置。不通过时显示 Xray 的报错，可选择「仍然切换」。
- **最低版本 26.1.23**：Xray 会静默忽略不认识的配置字段，低于该版本会让证书钉扎（`pinnedPeerCertSha256`）、REALITY 后量子验证、ECH 与 XHTTP 下行的 sing-box 拨号悄悄失效，因此不提供、也拒绝安装更旧的版本；手动放入的旧版本会在卡内警示。
- **安全切换**：代理运行中会整体重启一次代理（安装前提示）。新版本起不来时自动换回原来的 Xray 并重新连接。Xray 切换与 sing-box 内核更新互斥，一方进行中时另一方会提示稍后再试。
- **恢复随包版本**：在线安装的版本直接删除。你自己放进 `xray_core/` 的 `xray` 文件不会丢失：在线安装或恢复时会先另存为 `xray.custom-bak`。
- 「报告问题」与诊断报告会写明 Xray 的来源（随包 / 在线安装 / 自定义文件）与是否预发布。

### 改进
- 禁用状态的按钮现在会变淡，不再看起来可点（例如「已是当前版本」）。
- Xray 状态从 sing-box 的「内核管理」卡移到独立的 Xray 卡。

### 4.4.0 用户请注意
4.4.0 的应用内更新仍会检查上游 FlowZ，请从 [Releases](https://github.com/mutsuki14/FlowZX/releases/tag/v4.5.0) 手动下载并覆盖安装 4.5.0（节点、订阅与规则会保留；便携版请用新 exe 替换原目录中的旧 exe，数据在它旁边的 `data\`）。4.4.1 及以上版本可直接在应用内更新。如果 4.4.0 提示有新版本，请不要安装：那是上游 FlowZ 的安装包，不含 Xray 内核。

## FlowZX 4.5.0 — Choose the Xray core version (including pre-releases)

**Settings → Advanced** has a new **Xray core (sidecar)** card. You can install any official XTLS Xray release in-app, including pre-releases; it is verified against the official SHA2-256 and self-tested before switching, and you can go back to the bundled version with one click. On GitHub every release after v26.3.27 (the bundled version) up to v26.10.10 is a pre-release; turn on **Include pre-releases** to pick them.

**New:**
- **Version picker:**
  - Lists releases that have a build for your platform, marked pre-release, current or bundled, with a link to the release notes.
  - The list is cached for 10 minutes; **Refresh list** forces a refresh.
  - Xray never updates in the background. It is installed only when you click.
- **Include pre-releases:**
  - Off by default, so only stable releases are listed.
  - When on, releases GitHub marks as pre-release are listed too. They are not tested by FlowZX, so installing one asks for confirmation.
- **Integrity and compatibility checks:**
  - The main process resolves the download URL and digest from GitHub by version tag.
  - The archive must match the official SHA2-256, taken from both the GitHub API digest and the `.dgst` file downloaded directly from github.com (never via a mirror). The two must agree, and if neither is available the install is refused.
  - Only the `xray` binary is extracted, with a built-in unzipper that needs no system unzip or PowerShell.
  - `xray version` must match the chosen release.
  - The new core must pass `xray run -test` on your current config. If it doesn't, Xray's error is shown and you can **Switch anyway**.
- **Minimum version 26.1.23:** Xray silently ignores config fields it doesn't know, so older versions would quietly disable certificate pinning (`pinnedPeerCertSha256`), REALITY post-quantum verification, ECH and sing-box dialing of the XHTTP download leg. Older releases are not offered and are refused, and a manually placed older binary gets a warning on the card.
- **Safe switching:**
  - If the proxy is running it restarts once, and you are told before installing.
  - If the new version fails to start, FlowZX switches back to the previous Xray and reconnects.
  - An Xray switch and a sing-box core update can't run at the same time; the second one asks you to try again later.
- **Restore bundled version:**
  - An in-app install is deleted.
  - A custom `xray` you placed in `xray_core/` is never lost: it is kept as `xray.custom-bak` before being replaced or removed.
- **Reports:** "Report an issue" and the diagnostic report now include where the Xray core came from (bundled / installed in-app / custom file) and whether it is a pre-release.

**Improvements:**
- Disabled buttons are now dimmed instead of looking clickable (for example **Current version**).
- Xray status moved from the sing-box **Core Management** card to its own card.

**Upgrading from 4.4.0:** 4.4.0's in-app updater still checks upstream FlowZ, so download 4.5.0 from the [Releases page](https://github.com/mutsuki14/FlowZX/releases/tag/v4.5.0) and install it over your current version (nodes, subscriptions and rules are kept; for the portable build, replace the old exe in its folder, since its data lives in `data\` next to it). 4.4.1 and later update in-app. If 4.4.0 reports a new version, don't install it — it is an upstream FlowZ build without the Xray core.
