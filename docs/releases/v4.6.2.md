## FlowZX 4.6.2 — 修复选中 Xray 节点时自定义规则不生效

### 修复
- **Windows / macOS 的 TUN 模式下，规则页把流量指定到「不是当前选中的节点」时不生效。** 选中 Xray 节点、规则改走其它节点（例如日本网站走东京节点）时，连目标节点的拨号没有被排除出 TUN，被隧道重新捕获后回到全局出口或形成回环，规则看起来没有生效。现在与应用分流一样，把这些规则目标及其前置代理排除出 TUN。
- Linux 不受影响。系统代理模式下的域名规则此前就是生效的。

## FlowZX 4.6.2 — Custom rules work when an Xray node is selected

**Fixes:**
- **On Windows and macOS TUN, a rule that sends traffic to a node other than the selected one did not take effect.** With an Xray node selected and a rule pointing elsewhere (for example Japanese sites via a Tokyo node), the dial to that node was not excluded from the TUN, so the tunnel captured it again and sent it back to the global exit or into a loop. Those rule targets, and their front proxies, are now excluded from the TUN, the same way app-routing targets already were.
- Linux is unchanged. Domain rules in system-proxy mode already worked.
