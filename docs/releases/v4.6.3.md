## FlowZX 4.6.3 — 修复 Windows 上 TUN 网卡偶发无法创建

### 修复
- **Windows 上开启 TUN 时，偶尔一直连不上、TUN 网卡没有创建。** 提权服务在后台启动 sing-box 时没有使用无控制台启动标志，系统会为它初始化一个后台控制台，这一步偶尔卡住，sing-box 走不到创建 TUN 网卡。现在提权服务以 `CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW` 启动 sing-box，不再初始化控制台，也不会弹出黑框。
- macOS 与 Linux 不受影响。

## FlowZX 4.6.3 — Fix the TUN adapter sometimes not being created on Windows

**Fixes:**
- **On Windows, turning on TUN sometimes never connected and no TUN adapter was created.** The privileged helper service started sing-box without the no-console creation flag, so Windows set up a background console for it; that step could hang and sing-box never reached TUN setup. The helper now starts sing-box with `CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW`, so no console is set up and no window appears.
- macOS and Linux are unchanged.
